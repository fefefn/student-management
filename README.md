# Student Management System

A simple Student Management System developed to manage student records efficiently.

## 🚀 Features

- Add student records
- View student records
- Update student information
- Delete student records
- Manage student details

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📂 Project Purpose

This project was created to practice frontend development and CRUD-based application concepts.
